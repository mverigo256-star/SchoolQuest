# 🎯 SchoolQuest

Анонимное приложение для школьников: ученики придумывают задания, выполняют их в реальной жизни и получают награды.

## 🌟 Что умеет
- **Регистрация** по имени, паролю и классу
- **Создание заданий** с наградой (шоколадка, освобождение от домашки и т.д.)
- **Выполнение заданий** с фото-подтверждением
- **Общая лента** — все видят, кто что сделал
- **Лайки и комментарии** под записями
- **Рейтинг классов** и **Битва классов**
- **Зал славы** — топ-3 ученика школы
- **Уровни и XP** — за каждые 100 очков новый уровень
- **Достижения (бейджи)**
- **Задание дня** — особое задание с двойными очками
- **Личные сообщения** между учениками
- **Админ-панель** — создание официальных заданий, баны, удаление контента
- **Фильтр нецензурных слов**

## 🛠 Технологии
- HTML5, CSS3, JavaScript (ES6+)
- Firebase Firestore — облачная база данных
- Netlify — хостинг

## 🚀 Как запустить
Открыть файл `index.html` в любом браузере. Или онлайн: https://genuine-otter-d34fef.netlify.app
